# Targets

The standard verbs plus `clone` and creation scoped three ways:
`create_by_program_id`, `create_by_program_reference`, and
`create_by_proposal_reference`. `watch_edits` streams changes.

The same methods are CLI commands: {doc}`../cli/targets`.
